Korg M1 [Combi]

Combination Patch Editor

This editor works with the Korg M1 (1988) synthesizer in Combination mode. It edits Combination patches, which layer up to 8 Programs (timbres) with independent MIDI channel, key range, velocity range, and output routing.

Communicating with Edisyn

Set the M1's Global MIDI Channel to match Edisyn's MIDI output channel. To do this, hold GLOBAL and use the data slider or arrow buttons to select the MIDI channel.

The M1 must be in Combination mode (press COMBI) for requests and writes to work. While in Combination mode, Program Change messages select Combination numbers (not Programs).

Before writing patches to the M1, turn off Memory Protect. In Global mode, set MEM PROT to OFF.

Requesting and Sending Patches

Because the M1 has no direct "request combination by number" SysEx command, Edisyn will first send a Program Change to select the desired combination, then request the current combination dump. A short settling delay is inserted automatically.

To send a combination to the M1's working memory, use Send to Synth. To write a combination to a specific memory slot, use Write to Synth and enter a bank (Internal or Card) and combination number (00–99).

Combination Types

The M1 supports five combination types:

  • Single — one timbre plays across the full keyboard
  • Layer — two timbres sound together
  • Split — two timbres divided by key range
  • Vel. Switch — two timbres switched by velocity
  • Multi — up to 8 timbres with independent MIDI channels, key windows, and velocity windows (multitimbral mode)
In Single, Layer, Split, and Vel. Switch types, only Timbres 1 and 2 are active. In Multi type, all 8 timbres can be active.

Timbre Parameters

Each timbre has:

  • Program — selects which M1 Program plays on this timbre (I00–I99 = Internal, C00–C99 = Card)
  • Level — output volume (0–99)
  • Transpose — pitch shift in semitones (-12 to +12)
  • Detune — fine pitch in cents (-50 to +50)
  • Pan — stereo placement (0–13)
  • Ins Mode — when checked, this timbre acts as an independent instrument
  • Key Win Top / Bottom — MIDI note range for this timbre (0=C-1, 127=G9)
  • Vel Win Top / Bottom — velocity range for this timbre (1–127)
  • MIDI Ch — MIDI channel this timbre responds to (1–16)
  • On — enable/disable this timbre
  • Prog Chg / Damper / After Touch / Ctrl Chg — which MIDI controllers this timbre responds to


Memory Allocation and Card Bank

The M1 can be configured for either 100 or 50 Combinations. Combination numbers 00–99 are valid in the 100-combination allocation; 00–49 in the 50-combination allocation. Writing to the Card bank requires a RAM card with write-protect off.

Effect Parameters

The M1 has 34 effect types, each with up to 8 parameters whose meaning varies by type. Edisyn displays these as generic P1–P8 dials (0–255 range). Consult the M1 Owner's Manual (Section *11, page 129) for parameter definitions for each effect type.
