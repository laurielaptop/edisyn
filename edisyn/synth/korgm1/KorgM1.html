Korg M1

Program Patch Editor

This editor works with the Korg M1 (1988) synthesizer. It edits Program patches (single-patch mode only; Combination mode is not currently supported).

Communicating with Edisyn

Set the M1's Global MIDI Channel to match Edisyn's MIDI output channel. To do this, hold GLOBAL and use the data slider or arrow buttons to select the MIDI channel.

Before writing patches to the M1, turn off Memory Protect. In Global mode, set MEM PROT to OFF. If memory protect is on, write commands will fail silently (the M1 will return a Write Error).

Requesting and Sending Patches

Because the M1 has no direct "request patch by number" SysEx command, Edisyn will first send a Program Change to select the desired patch, then request the current program dump. A short settling delay is inserted automatically.

To send a patch to the M1's working memory, use Send to Synth. To write a patch to a specific memory slot, use Write to Synth and enter a bank (Internal or Card) and patch number (00–99).

Memory Allocation

The M1 can be configured in Global mode for either:

  • 100 Programs / 100 Combinations (default)
  • 50 Programs / 50 Combinations (alternate, reserves more sequencer memory)
Patch numbers 00–99 are valid in the 100-program allocation; 00–49 in the 50-program allocation. Edisyn always shows 100 patch slots; writing beyond the valid range will fail.

Card Bank

Writing to the Card bank requires a RAM card inserted with its write-protect switch off. If no card is present, write commands to the Card bank will fail.

EG SW / Polarity

The M1 stores EG Time KBD Track, Velocity Switch, and Polarity settings as packed bit fields. In this editor they appear as raw byte values (0–255) on the Mod tab under EG SW / Polarity. Bit 0 = Attack Time SW, Bit 1 = Decay Time SW, Bit 2 = Slope Time SW, Bit 3 = Release Time SW, Bit 4 = Attack Polarity, Bit 5 = Decay Polarity, Bit 6 = Slope Polarity, Bit 7 = Release Polarity.

Effect Parameters

The M1 has 34 effect types, each with up to 8 parameters whose meaning varies by effect type. Edisyn displays these as generic P1–P8 dials (0–255 range). Consult the M1 Owner's Manual (Section *11, page 129) for parameter definitions for each effect type.

Librarian Support

Edisyn can read and write individual patches. Use Download Bank from Synth to retrieve patches one by one. Bank SysEx bulk-download (4CH) is not currently implemented.
