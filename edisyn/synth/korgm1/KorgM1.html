Korg M1

Patch editor for the Korg M1 synthesizer (1988).

MIDI Setup: Set the M1's Global MIDI Channel to match Edisyn's output channel. Enable Memory Protect OFF in Global mode before writing patches.

Memory Allocation: The M1 supports either 100 Programs / 100 Combinations or 50/50 (with more sequencer memory). Program numbers 00–99 (or 00–49) are valid depending on your Global setting.
